طريقة سير العمل

  1. Intake

    هرمس يفحص المطلوب ويقارن بين الموجود في GitHub والبنية الحية.

  2. Planning

    تقسيم المهمة إلى issues قابلة للتنفيذ مع labels وربطها بالمشروع.

  3. Execution

    تشغيل الأدوات المناسبة: terminal, GitHub, web, browser عند الحاجة.

  4. Verification

    فحص النتائج الفعلية على GitHub وعلى المسار الإنتاجي قبل الإنهاء.
