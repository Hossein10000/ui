# لوحة تحكم Hermes Agent

لوحة تحكم عربية متجاوبة لهاتف iPhone تم تصميمها لواجهة Hermes agent.

## المميزات
- واجهة عربية بالكامل (اتجاه من اليمين إلى اليسار)
- تصميم متجاوب يعمل بشكل جيد على الهواتف الذكية وخاصة iPhone
- عرض حالة النظام والخدمات النشطة
- قسم للسجلات الأخيرة
- أزرار للإجراءات السريعة

## technologيات المستخدمة
- HTML5
- CSS3 (بسيط ومخصص)
- لا أطر عمل خارجية لتجنب الوزن الزائد

## التخصيص
يمكن تعديل النصوص والألوان والأزرار في ملف `index.html` حسب الحاجة.

## الترخيص
هذا المشروع خاص بـ Hermes agent.
