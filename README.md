# AgentHost UI Dashboard

واجهة عربية حديثة، خفيفة، ومبنية بالكامل بالكود لعرض:

- ساحة شات تنفيذية
- صندوق وارد منظم للنتائج والملفات
- ملخص سير العمل والبنية
- عرض جاهز للربط لاحقًا مع Hermes API

## النشر الحالي

- المسار الإنتاجي المضمون: `https://agenthost.tech/ui/`
- المسار الاختياري لاحقًا بعد إضافة DNS: `https://ui.agenthost.tech/`

## التقنية

- HTML
- CSS
- JavaScript بسيط
- Nginx
- Traefik + Authelia

## التشغيل

```bash
cd /root/ui
docker compose up -d
```

## الهدف

هذا المشروع يمثل تسليم واجهة Frontend نهائية قابلة للاستلام، مع نشر فعلي على الدومين، ومهيأة للربط اللاحق بخدمات Hermes الحية.
